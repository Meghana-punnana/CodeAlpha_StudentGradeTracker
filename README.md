Student Grade Tracker

About the Project

Student Grade Tracker is a Java-based application developed as part of my CodeAlpha Java Internship.

It helps calculate and display student academic performance based on subject marks.

Features

- Enter the number of students.
- Enter student names.
- Enter marks for multiple subjects.
- Calculate average marks.
- Find highest and lowest marks.
- Display student grades.
- Validate marks between 0 and 100.

Technologies Used

- Java
- Scanner
- ArrayList
- VS Code
